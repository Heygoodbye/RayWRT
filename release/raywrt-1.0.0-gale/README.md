# RayWRT 1.0.0 Gale build source

Tested only on Google WiFi AC-1304 (Gale), OpenWrt 25.12.5. This directory contains the frozen 1.0.0-r5 package, pinned revisions, build and image verifier scripts, source checksums, fixtures, and recovery guides.

See [BUILD.md](BUILD.md) to build on Linux and [FINAL_V1.md](FINAL_V1.md) for image identity. Download binaries from [GitHub Releases](https://github.com/Heygoodbye/RayWRT/releases/tag/v1.0.0). Build and image verification passed; formal clean-sysupgrade acceptance remains pending.

SOURCE-MANIFEST.sha256 is relative to package/luci-theme-raywrt. BUNDLE-MANIFEST.sha256 covers the publicly tracked source files in this directory. Local artifacts and private operational audits are excluded from the public source manifest.
